
# CampusFlow - Student Assignment Tracker

CampusFlow is a student productivity project that helps college students organize assignments, track deadlines, and manage academic tasks.

## Problem
Students often manage assignments from multiple subjects. Keeping track of deadlines and deciding which task to complete first can be difficult.

## Solution
CampusFlow provides a single dashboard to organize assignments and deadlines.

## Features
- Add assignments with subject, due date, and priority
- Search assignments
- Filter by subject
- View tasks that are due soon
- Mark assignments as completed
- Track completion progress
- Responsive layout for desktop and mobile
- Save tasks in browser local storage

## Target Users
College students managing multiple subjects and deadlines.

## Technology Stack
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Success Metrics
1. Time required to identify the next assignment deadline.
2. Percentage of users who can add and complete a task without assistance.

Target: Reduce task-identification time by 25% and achieve successful task completion for at least 4 out of 5 test users. These are proposed targets, not measured results.

## Research Status
Published research motivates investigating missed deadlines and student time management. CampusFlow itself still requires user testing before its effectiveness can be established.
