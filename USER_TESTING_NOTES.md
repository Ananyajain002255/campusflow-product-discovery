
# CampusFlow - User Testing Notes

## Objective
Evaluate whether college students can understand and use the assignment tracker without assistance.

## Participants
Plan to test with 3-5 college students who manage assignments from multiple subjects.

## Testing Tasks
1. Find the next assignment due.
2. Add a new assignment with a subject and deadline.
3. Filter assignments by subject.
4. Mark an assignment as completed.

## Observations to Record
For each participant, record:
- Participant ID (P1, P2, etc.)
- Task attempted
- Completed successfully? (Yes/No)
- Time taken
- Where the participant hesitated
- Feedback or suggestions

## Questions to Ask
1. Was it easy to understand the dashboard?
2. Could you identify your next deadline quickly?
3. What feature was confusing or missing?
4. Would you use this tool during a semester? Why?
